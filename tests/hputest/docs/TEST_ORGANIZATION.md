# 当前组织与参数规则

唯一权威清单为`../cases.tsv`。00～02与06保持原测试；只精简03～05与07。

| 组 | 参数 | 数量 |
|---|---|---:|
| 03 | N1024，输入Q数4；九条基础指令 | 9 |
| 04 | N1024，输入Q数4；三个基本算子＋三算法KeySwitch | 6 |
| 05 | N1024，输入Q数4；CKKS/BFV/BGV各五种库操作 | 15 |
| 07 | N1024和N8192，输入Q数均4；三算法各六种操作 | 36 |

组内从01连续编号，全部两位。03～05源码放在组目录根；07按01_n1024、02_n8192分目录。每行唯一对应同名C文件，不能共享main，也不能把多个N串行塞进一个ELF。原参数矩阵、原N4096定向和特殊回归不再保留源码，旧新编号关系仅用于查旧日志。

每项C显式写配置、具体发令、等待和结果/guard检查；错误分支带文件与行号。旁侧ASM必须与上游实际程序一致，不能以展示副本代替执行序列。低层接口可复用，完整流程仍在每项main内。

level按输入Q的RNS分量数计，不含P；03是raw模上下文测试，不代表某个加密方案。05是完整库操作，04的KeySwitch核心不等同完整Reline。BGV性能输入已由旧Q3改为Q4，须重新验证，不继承旧参数的测量结果。

同样N/level不代表不同组使用完全相同密文/CF/旋转参数。精确Q/P、scale、密钥、物理布局和golden以本次原生包metadata为准；CPU性能对照也应取07自己的输入与参数。
